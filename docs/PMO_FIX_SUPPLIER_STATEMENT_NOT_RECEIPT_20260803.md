# PMO 정정 결정 — 거래처 원장잔액과 매입·입고내역 분리

- 결정일: 2026-08-03
- 대상: 삼양스파이스 거래처 원장 반영 오류
- 승인 기준: GPT(PMO)

## 문제

삼양스파이스 거래처 원장의 전기이월 및 월별 매입 합계가 `purchases` 테이블에 `STATEMENT` 단위의 가상 매입행으로 생성됐다. 이 때문에 실제 입고가 아닌 `2026-07 원장 / 1 STATEMENT` 등이 매입·입고내역에 노출됐다.

## 정정

1. 삼양스파이스 가상 원장 매입행 8건 삭제
2. 해당 가상행에 연결된 지급배부 10건 삭제
3. 실제 원재료 입고이력 49건 유지
4. 승인된 거래처 원장 7개월분 유지
5. 2026-07-30 기준 확정 미지급잔액 11,786,800원 유지
6. 매입 재무요약 API는 `purchase_supplier_statement_balances`의 최신 승인 잔액을 직접 사용
7. `STATEMENT` 단위 또는 `DB-STMT-*` 번호를 가진 자료가 `purchases`에 다시 입력되지 않도록 DB 트리거 차단

## 운영 원칙

- 거래처 원장잔액은 재고·입고 데이터가 아니다.
- 거래처 원장자료는 `purchase_supplier_statement_balances`에서만 관리한다.
- 실제 품목, 수량, 입고일이 확인된 자료만 매입·입고내역에 등록한다.
- 월별 합계나 전기이월금은 가상 품목으로 만들지 않는다.
- 거래처 원장 승인잔액은 매입처 재무요약의 미지급잔액 기준으로 사용하되, 입고내역에는 노출하지 않는다.

- 남은 `STATEMENT` 매입행: 0건
- 보존된 삼양스파이스 실제 원재료 매입·입고 연결행: 49건
- 승인 원장자료: 7건
- 최신 승인잔액: 11,786,800원
- 관련 원재료 현재고 합계: 323,858.360g
