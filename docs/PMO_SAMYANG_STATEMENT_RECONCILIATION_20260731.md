## 3. MONI 반영 원칙

1. 거래처 원장과 기존 MONI 입고자료의 날짜와 품목별 수량이 여러 건 불일치한다.
2. 원장을 그대로 신규 입고로 생성하면 현재고가 중복 증가할 위험이 있다.
3. 기존 삼양스파이스 입고 49건은 재고이력으로 보존한다.
4. 해당 49건은 과거 마스터단가 기반 예상금액이므로 금융 계산에서는 `EXCLUDED` 처리한다.
5. 거래처 원장의 월계는 재고와 분리된 금융전용 확정행 8건으로 등록한다.
6. 거래처 원장의 수금 9회는 FIFO 기준으로 10개 지급배부행에 반영한다. 2026-06-22 지급 3,000,000원은 4월분 2,198,600원과 5월분 801,400원으로 분할한다.
7. 월별 거래처 잔액자료 7건은 `VERIFIED / APPROVED` 상태로 저장한다.
8. 은행 거래자료와 일치한 기존 삼양스파이스 지급후보 6건, 19,311,600원은 `MATCHED` 처리하되 금융원장에 중복 반영하지 않는다.
