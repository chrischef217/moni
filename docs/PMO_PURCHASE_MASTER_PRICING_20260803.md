# PMO 결정 — 매입·입고 기준단가 및 단위환산

- 확정일: 2026-08-03
- 적용 시스템: MONI 매입관리 → 매입·입고 관리
- 승인 기준: GPT(PMO)

## 1. 기준정보 의미

`raw_materials.unit_price_per_kg`는 기존 필드명과 달리 실제 운영상 **kg당 단가가 아니라 기준 포장 1EA의 매입단가**이다.

- 기준 포장중량: `raw_materials.packing_weight_g` (g/EA)
- 기준 개당 매입단가: `raw_materials.unit_price_per_kg` (원/EA)
- 부재료 기준단가: `packaging_materials.unit_price` (원/EA)

필드명만 보고 kg단가로 해석하지 않는다.

## 2. 원재료 입고 환산식

기준 포장중량을 `W g/EA`, 기준 개당단가를 `P 원/EA`, 입력수량을 `Q`라고 한다.

- EA 입력: 재고입고량 = `Q × W` g, 입력단가 = `P` 원/EA
- kg 입력: 재고입고량 = `Q × 1,000` g, 입력단가 = `P × 1,000 ÷ W` 원/kg
- g 입력: 재고입고량 = `Q` g, 입력단가 = `P ÷ W` 원/g
- 공급가액 = `재고입고량 ÷ W × P`

원재료 재고는 항상 최종적으로 정수 g로 환산한다.

## 3. 부재료 입고 환산식

- 입력단위는 EA만 허용한다.
- 수량은 정수만 허용한다.
- 공급가액 = `입고수량 × 부재료 마스터 EA 단가`

## 4. 세액 및 총액

- 과세 매입처: 부가세 = 공급가액의 10%
- 면세 또는 영세율 매입처: 부가세 = 0원
- 총 매입금액 = 공급가액 + 부가세

## 5. 시스템 통제

- 화면의 단가·공급가·부가세·총액은 자동 계산하며 직접 수정하지 않는다.
- 서버는 브라우저가 보낸 단가와 공급가를 신뢰하지 않고 마스터를 다시 조회해 계산한다.
- 엑셀 일괄등록의 단가·공급가·부가세도 서버에서 자동 계산한다.
- 포장중량 또는 기준단가가 없는 품목은 등록을 차단하고 원재료 관리에서 기준정보를 먼저 입력하게 한다.
- EA는 정수만 허용한다.
- kg 입력은 0.001kg 단위까지 허용하며 g 환산 후 정수여야 한다.
- 매입등록 또는 수정 때문에 원재료 마스터의 기준 개당단가를 kg 환산단가로 덮어쓰지 않는다.

## 6. 기존 데이터 보호

- 기존 매입·입고·재고·지급 데이터는 일괄 재계산하지 않는다.
- 기존 매입행은 품목·매입처·수량·단위가 변경될 때만 최신 마스터 기준으로 재계산한다.
- 날짜·비고·지급예정 정보만 수정할 때는 기존 확정 금액을 보존한다.

## 7. 검증

기준 포장 18,000g, 개당단가 20,000원인 원재료를 대상으로 트랜잭션 롤백 테스트를 수행했다.

- 1EA 입력: 입고 18,000g / 공급가 20,000원 / VAT 2,000원 / 총액 22,000원
- 18kg 입력: 입고 18,000g / 공급가 20,000원 / VAT 2,000원 / 총액 22,000원
- 두 방식 결과 일치
- 원재료 마스터 단가 불변
- 테스트 데이터 0건 잔존
